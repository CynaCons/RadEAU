# v0.1.14 contract — commands, events, types (pinned by the coordinator)

Every worker builds against exactly this. Spec: docs/SRS_capture.md §8–§10 (CP-017..024), docs/SRS_visual_ui.md §5.3, §5.9, VU-028. Decision: docs/decisions/D10-recording-format.md.

## Replay (Rust: src-tauri/src/replay.rs + channel.rs PcapSource; TS: src/runtime/desktop.ts wrappers + src/runtime/replayStore.ts)

Rust types (serde `rename_all = "camelCase"`):
```rust
pub struct ReplayInfo { pub path: String, pub frames: u64, pub first_ts_ns: u64, pub last_ts_ns: u64,
                        pub duration_ns: u64, pub interfaces: Vec<String>, pub comment: Option<String>, pub cut: bool }
pub struct ReplayPosition { pub state: &'static str /* "playing" | "paused" | "ended" */, pub t_ns: u64 /* relative to first_ts_ns */,
                            pub frame: u64, pub frames: u64, pub duration_ns: u64, pub speed: Option<f64> /* None = max */ }
pub struct ReplaySeek { pub t_ns: u64, pub frame: u64 }
```
Commands (all `#[tauri::command]`, registered in main.rs by the coordinator):
- `replay_open(path: String) -> Result<ReplayInfo, String>` — CP-020; runs the prepare pass on a blocking thread; emits `replay:prepare {done, total}` (bytes) for files > 16 MiB. Keeps the prepared index in `ReplayState` for the next session on that path.
- `replay_play() / replay_pause() / replay_step() -> Result<(), String>` — CP-021; error "no replay session" when the running session is not a file replay.
- `replay_seek(t_ns: u64) -> Result<(), String>` — CP-022; t_ns relative to the file's first timestamp, clamped to [0, duration].
- `replay_set_speed(speed: Option<f64>) -> Result<(), String>` — allowed {0.1, 0.25, 0.5, 1, 2, 5, 10} or null (max); anything else is an error.
A replay session is started with the existing `capture_start` and `SourceSpec::Pcap { path, pace }`; `pace` stays accepted ("realtime" → speed 1, "fast" → max) for compatibility. New sessions start **playing**.
Events: `replay:position` (ReplayPosition, ≈10 Hz while playing + immediately after every command and at end), `replay:seek` (ReplaySeek; the UI clears its trace ring on it), `replay:prepare {done, total}`.

## Recording (Rust: crates/radeau-pcap PcapngWriter + src-tauri/src/recording.rs)

- Files: `radeau-<yyyyMMdd-HHmmss>.pcapng`, rotation `-001`, `-002` … at `rotate_bytes` (default 512 MiB; `recording_rotate_set(mib: u32)` / part of `recording_state`).
- `recording:state` gains `rotateMib: number` and `files: number` (files written this session). `recording_list()` lists `.pcap` and `.pcapng`.
- The writer needs session metadata: `RecordingMeta { source_kind, source_detail, timestamp_source, scenario: Option<String>, started: SystemTime }` passed by capture.rs at begin (coordinator wires it).

## Decoded export (Rust: src-tauri/src/export.rs)

- `export_jsonl(path: String, from: ExportFrom) -> Result<ExportJsonlResult, String>`, `ExportFrom = "ring" | { file: String }` (serde untagged / tagged as `{"kind":"ring"}` / `{"kind":"file","path":…}` — use the tagged form), `ExportJsonlResult { frames: u64, bytes: u64, path: String }`; event `export:jsonl {done, total}`.
- Line shape: `{idx, tNs, dir, len, protocol, name, type, key, layers: [{protocol, summary, fields: [{name, value}]}], payloadHex, decoded?}` (CP-024).
