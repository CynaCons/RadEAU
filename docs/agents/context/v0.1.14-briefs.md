## W-REC — pcapng recordings (PLAN v0.1.14 tasks "pcapng writer…", "Network timestamp…"; CP-017, CP-018, CP-019)
1. crates/radeau-pcap: `PcapngWriter<W: Write>` — SHB (byte-order magic, version 1.0, section length -1, options `shb_userappl`, `opt_comment`), IDB(s) (link type 1, snaplen 262144, options `if_name`, `if_tsresol`=9), EPB (interface id, 64-bit ns timestamp split high/low, captured/original length, data padded to 32 bits, option `epb_flags` with direction bits 01 inbound / 10 outbound only when known), options terminated by opt_endofopt, block total length repeated. Tests: round-trip through the crate's own PcapReader (timestamps ns-exact, bytes identical, direction flags read back as CP-009 expects), a strict structural walker test (every block length multiple of 4, trailing length equals leading), and odd-length payload padding.
2. src-tauri/src/recording.rs: write pcapng instead of classic pcap; name `.pcapng`; rotation at `rotate_bytes` (default 512 MiB, new `recording_rotate_set(mib)` command + `rotateMib`/`files` in RecordingStateDto) — rotate between records, each file a complete pcapng with its own SHB/IDB; accept a `RecordingMeta` at begin (contract) and write it into the SHB comment; `recording_list()` returns `.pcap` and `.pcapng`. Keep the bounded queue / drop-oldest / 256 KB–2 s flush exactly (CP-017). The EPB timestamp is the frame's ts_ns as given by the reader (CP-019) — direction passed through (extend `RecordingHandle::push(ts_ns, dir, wire)`; capture.rs call site is the coordinator's — leave a compile error message in your report if the signature changes, or keep a compatible wrapper).
3. Log recording start/stop/rotate/error lines (CP-007 log).
Gates: Rust gates; a test that records frames, closes, reopens with PcapReader and compares.

## W-REPLAY — replay transport (tasks "Replay prepare…", "Replay worker…", "Seek…"; CP-020..023)
1. src-tauri/src/replay.rs (new): `ReplayState` (managed by Tauri; holds the prepared `ReplayIndex` per path and the live `Arc<ReplayControl>` of the running replay session), `prepare(path) -> (ReplayInfo, ReplayIndex)` — one pass with radeau-pcap's reader: frame count, first/last ts, interfaces (pcapng IDB if_name or "pcap"), SHB comment, checkpoints every 5,000 frames {byte offset where the parser can restart (block boundary for pcapng — the reader must be able to resume at an offset with the header/IDBs re-supplied: design this, e.g. re-feed the file header bytes then seek), ts, frame}. Commands per contract.
2. `ReplayControl` (atomics + a small mutex): state playing/paused, speed (Option<f64>), pending seek target, pending step, anchor (wall Instant, file ts). PcapSource (channel.rs) reads it: absolute schedule `due_wall = anchor_wall + (ts − anchor_ts)/speed`, re-anchored on play/speed/seek; 50 ms sleep cap; paused → returns Idle without reading; step → deliver exactly one frame then pause; seek → reposition via the index (no emit while skipping to target), then signal capture.rs to clear the core frame ring and emit `replay:seek`. `pace` "realtime"/"fast" maps to speed 1 / max for compatibility.
3. Position events at ≈10 Hz + on every command + at end, through the CaptureEvents seam in capture.rs (add `emit_replay_position`, `emit_replay_seek` to the trait; AppHandle impl emits `replay:position` / `replay:seek`).
4. Tests (unit, with the mock CaptureEvents and the checked-in fixture fixtures/pcap/sensor-fusion-5s.pcap): prepare counts + checkpoints; schedule math as pure functions (speed change re-anchors, no drift over 10k frames); pause holds; step = one frame; seek lands on first frame ≥ target with nothing earlier emitted; max speed never drops (CP-004).
Gates: Rust gates.

## W-EXPORT — decoded JSONL export (task "Decoded JSONL export…"; CP-024)
src-tauri/src/export.rs (new): `export_jsonl(path, from)` per contract — from the core FrameRing (snapshot the frames under the lock quickly, dissect outside the lock) or from a pcap/pcapng file (stream records through radeau-pcap + classify + dissect); one JSON object per line via a BufWriter; catalog-decoded signals when a catalog is loaded (use the same path as frame_detail); progress event every 1% / 250 ms; bounded memory for files (streaming). Tests: export of the 5 s fixture → line count == frame count, every line parses, protocol/name agree with classify, layers agree with dissect for a sample of frames.
Gates: Rust gates.
