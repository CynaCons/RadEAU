# Worker rules (all briefs)

Repo: C:\dev\public-repo\RadEAU — Tauri 2 (Rust core in src-tauri + workspace crates) + React 19 + TypeScript + Vite + MUI; an automotive Ethernet trace analyzer. A coordinator (Claude) runs the authoritative gates and commits.

- Sibling workers edit OTHER files in parallel. If typecheck/build breaks in a file you do not own, report it; do not fix it.
- Your process is killed at ~300 s. Disk state persists and you are re-spawned with "continue". Work in small complete steps; never leave a file half-rewritten. On a continuation: run `git status` and `git diff --stat` first, read what you already changed, never revert it, and carry on from there. Start long cargo commands in the background and poll.
- Prohibited: commits, git history rewrites, `git checkout`/`git stash`/`git reset` of any file, edits to PLAN.md / PRD.md / docs/ (except files your brief names), reformatting code you did not otherwise change, new dependencies unless the brief allows.
- SRS tables: never weaken or reword a requirement's scope. If only part ships, report it — the coordinator supersedes and splits rows.
- Keep every `data-testid` and every user-visible behaviour unless the brief says otherwise.
- Verify once at the end: run each gate once; rerun only after fixing a red.
- Final report shape: CHANGED (file — one line each) · GATES (literal last lines of each gate) · OPEN (not done + why) · RISKS. Never claim done without gate output.
- Rust: run cargo with `CARGO_TARGET_DIR=C:/dev/public-repo/RadEAU/target/<your-worker-id>` (absolute) — never the default target dir (a running radeau.exe locks it). Gates for Rust: `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo fmt --all -- --check`.
- TS gates: `npx tsc --noEmit`, `npm run lint`, `npx vitest run`.
